## 📌 Project Overview

**Student Assessment Performance Dashboard** is an interactive **Power BI dashboard** designed to analyze student assessment performance across different departments, courses, batches, and time periods.

The dashboard transforms assessment data into meaningful visual insights that help users understand:

- 📚 Course-wise performance
- 🏫 Department-wise average scores
- 📅 Monthly performance trends
- 👥 Batch-wise analysis
- 📊 Overall student assessment performance

The complete dashboard is developed using **Microsoft Power BI**.

# 🧹 Data Preparation

The data was prepared before creating the final dashboard.

### Data Preparation Steps

1. 📥 Import the source data into Power BI
2. 🔍 Inspect available columns and data types
3. 🧹 Clean inconsistent or missing values
4. 🔄 Convert columns into appropriate data types
5. 🔗 Combine related assessment and course information
6. 📅 Prepare assessment dates for monthly analysis
7. 📊 Create the required calculations
8. 📈 Build visuals using the cleaned data

# 🧮 DAX & Measures

Power BI measures were used to calculate important performance metrics.

### Example Measure

```DAX
Avg Score =
AVERAGE(assessments[score])
```

This measure calculates the **average assessment score** used throughout the dashboard.

# 📊 Dashboard

## 🎓 Student Assessment Performance Dashboard

The main dashboard provides an interactive view of student assessment performance.

### Main Visuals

#### 📊 Average Score by Department

A clustered bar chart is used to compare the **average score across courses and departments**.

It helps identify differences in academic performance between departments.

---

#### 📈 Monthly Average Score

A line chart shows the **monthly average assessment score**.

This allows users to observe how performance changes over time.

---

#### 🎛️ Batch Slicer

A **Batch slicer** allows users to filter the dashboard according to the selected batch/session.

When a batch is selected, the related dashboard visuals update interactively.
